# IRISA branding assets

Place approved IRISA artwork here:
- `icon.png` — application icon source;
- `adaptive-icon.png` — Android adaptive icon foreground;
- `splash.png` — splash artwork.

Do not use placeholder images for production. The current app configuration continues to use upstream artwork until the IRISA assets have been supplied and validated. Brand metadata is in `config/irisa-brand.example.json`.
